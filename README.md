# 📚 Atividades JPA

Repositório criado para reunir atividades e exercícios desenvolvidos durante os estudos de **Java e JPA (Java Persistence API)**.

## 📌 Sobre o projeto

O repositório contém diferentes atividades práticas desenvolvidas para exercitar conceitos de desenvolvimento em Java e persistência de dados.

As atividades estão organizadas em pastas independentes, facilitando a consulta e o acompanhamento dos exercícios.

## 🛠️ Tecnologias

* Java
* JPA (Java Persistence API)

## 🎯 Objetivo

Praticar conceitos de programação em Java e persistência de dados utilizando JPA, por meio de diferentes exercícios e aplicações desenvolvidos durante os estudos.
